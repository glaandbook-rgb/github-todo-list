## ขอบเขต

## สิ่งที่ต้องตรวจ
ตรวจ flow เต็มตั้งแต่ต้นจนจบ

```
สมัครสมาชิก → เข้าสู่ระบบ → หน้า Home → กรอง/ค้นหา
→ เปิดรายละเอียดแอป → ใช้ Calculator → กดซื้อ
→ Checkout (mock) → ได้ License Key → My Library
```

## E2E ที่ต้องผ่านครบ 8 journey
1. สมัครสมาชิก / เข้าสู่ระบบ
2. เข้า `/library` โดยไม่ login ต้องถูกเด้งออก
3. ค้นหาและกรองแอปจากหน้า Home
4. เปิดหน้ารายละเอียดแอป
5. ใช้ Calculator แล้วตัวเลขเปลี่ยนตาม slider
6. ซื้อแอป (mock) แล้วได้ License Key
7. License Key ปรากฏใน My Library
8. ผู้ใช้คนอื่นต้องไม่เห็น License ของเรา

## Regression ข้ามโมดูลที่ต้องตรวจ
- กรองแล้วกดเข้าแอป แล้วกดย้อนกลับ ตัวกรองต้องยังอยู่
- ซื้อแอปแล้วกลับมาหน้าเดิม ปุ่มซื้อต้องเปลี่ยนสถานะ ไม่ให้ซื้อซ้ำ
- Sustainable Score ที่หน้า Home กับหน้ารายละเอียดต้องตรงกัน
- ราคาที่หน้ารายละเอียด หน้า Checkout และใน `orders.price_paid_thb` ต้องตรงกันทั้งสามจุด

## สิ่งที่ต้องรายงาน
1. ปัญหาที่พบจากการรวมโค้ด
2. ต้นตอของแต่ละปัญหาและเจ้าของโมดูล
3. สิ่งที่แก้ไป
4. ผลการรัน `npm run test` และ `npm run test:e2e`
5. ปัญหาที่ยังค้างอยู่

**STOP.**
